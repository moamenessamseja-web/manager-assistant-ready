# مساعد الإدارة — Manager Assistant

تطبيق Flutter لأندرويد موجّه لأصحاب المشروعات الصغيرة (كافيه/مطعم/محل) في مصر.
صاحب النشاط يتكلم أو يكتب بالعامي المصري، والتطبيق يفهم الأمر وينفّذه على
الحساب الصحيح ويحفظ النتيجة — **بدون إنترنت وبدون أي مفتاح API**.

## ماذا يفعل الآن؟

- **محرك أوامر محلي** يفهم العامي المصري على الجهاز مباشرة:
  - تسجيل الحضور: «سجل حضور أحمد»، «أحمد حضر النهارده»، «اعتبر أحمد حاضر».
  - السلف والخصومات والمكافآت: «خصم ألف جنيه من أحمد»، «على أحمد سلفة ١٠٠٠ جنيه».
  - الموردين والتوريدات: «سالم جاب بضاعة بخمسة آلاف»، «دفعت لسالم ألفين»، «سجل توريد من سالم».
  - الاستعلامات: «مين محضرش النهارده؟»، «مين عليه فلوس؟»، «كام للمورد محمود؟»، «مين أخد سلف الأسبوع ده؟».
  - الموظفون والموردون الجدد، الالتزامات، وقواعد المتابعة المتكررة.
- **فهم الأرقام العربية والهندية** (١٠٠٠ / ۵۰۰) وكلمات الأعداد (ألف، ألفين، خمسة آلاف).
- **سياق محادثة دائم**: بعد «مين محضرش النهارده؟» تقدر تقول «سجلهم حضور»،
  والتنفيذ يحصل على **معرّفات السجلات المحفوظة** نفسها — مش بالاعتماد على نص المحادثة.
- **إكمال الاستيضاح**: «سجل توريد من سالم» → يسأل القيمة → «٥٠٠٠ جنيه» → يكمّل العملية.
- **حل التباس الأسماء**: يعرض الخيارات بمعرّفاتها، وتختار بـ«التاني»/«الأول» أو «أحمد سواق».
- **الشاشات اليدوية كاملة** كبديل دائم: الموظفون، الموردون، اليوم، الذاكرة، البريف، القواعد.
- تنبيهات محلية للمتابعة، وإدخال صوتي بالعربية المصرية.

## كيف يعمل الفهم؟

1. **محليًا أولاً** (`lib/services/local_command_parser.dart`): تطبيع النص العربي،
   تحديد النية، استخراج الأشخاص والمبالغ والكميات والتواريخ. يعمل offline بالكامل.
2. **Gemini اختياري** (`lib/services/gemini_service.dart`): يُستخدم فقط للأوامر
   المعقدة التي لا يفهمها المحلل المحلي. **معطّل افتراضيًا**، وله حقل في
   الإعدادات لإدخال مفتاح المستخدم نفسه، وغيابه أو فشله **لا يعطّل أي عملية محلية**.
3. **لا تخمين**: لو البيانات ناقصة، التطبيق يسأل بدل ما ينفّذ عملية مالية على شخص غلط.

## التشغيل للمطور

```bash
flutter pub get
flutter run
```

### البناء

```bash
flutter build apk --release
```

أو ارفع ZIP إلى Codemagic وسيبني `codemagic.yaml` ملفات Android ثم APK.
الـ `codemagic.yaml` و`.github/workflows/build-apk.yml` يضيفان الأذونات المطلوبة
(`RECORD_AUDIO`, `POST_NOTIFICATIONS`, `INTERNET`) أثناء البناء.

## تشغيل الاختبارات

```bash
flutter test --exclude-tags live   # كل الاختبارات المحلية — بدون إنترنت وبدون مفتاح
flutter analyze
```

- اختبارات المحلل المحلي: `test/local_command_parser_test.dart` (تعمل offline بالكامل).
- اختبارات الموردين/الموظفين/النماذج: `test/supplier_test.dart`, `test/employee_test.dart`, `test/model_test.dart`.
- اختبار تكامل حقيقي مع Gemini: `test/gemini_live_test.dart` (وسم `live`) — **يُتخطّى
  تلقائيًا** لو متغير البيئة `GEMINI_API_KEY` غير موجود، والمفتاح لا يُخزَّن في المستودع أبدًا.

## ما يعمل دون إنترنت

كل العمليات المدعومة محليًا: الحضور، السلف، الخصومات، المكافآت، التوريدات، الدفعات،
إضافة الموظفين والموردين، الالتزامات، قواعد المتابعة، وكل استعلامات البيانات — كلها
تعمل offline. الإنترنت مطلوب فقط لو أردت استخدام خدمة المساعدة الإضافية الاختيارية.

## ملاحظة عن الخصوصية والمفاتيح

- **لا يوجد أي مفتاح API مدمج في الكود أو في التطبيق المنشور** — لا مفتاح تطوير،
  ولا مفتاح افتراضي. حقل مفتاح Gemini في الإعدادات اختياري بالكامل ويقبل فقط
  مفتاح المستخدم نفسه، ويُحفظ محليًا على جهازه فقط (لا يُرفع للمستودع أبدًا).
- بيانات النشاط تُخزَّن محليًا على الجهاز فقط.

## حدود هذه النسخة

- ليست نظام محاسبة أو Payroll قانوني. حساب المرتب مبسّط حسب الحضور والسلف،
  ويحتاج قواعد عملك الفعلية قبل الاعتماد المالي الواسع.
- تغيير اللغة يغطّي هيكل الواجهة (التنقل، العناوين، الإعدادات)؛ نص البيانات يفضل عربيًا.
- سلوك الإشعارات بعد إعادة تشغيل الجهاز وملتقط الصور لم يُختبرا على هاتف حقيقي بعد
  (الـ CI يثبت الترجمة والتغليف فقط).

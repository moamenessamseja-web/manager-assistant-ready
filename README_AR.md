# مساعد الإدارة — Manager Assistant

نسخة MVP جاهزة كمشروع Flutter لأندرويد، مبنية على الفكرة الموجودة في ملف المواصفات المرفق.

## ماذا يفعل الآن؟
- شات عربي للمهمات والديون والموردين والحجوزات والإيجار.
- تحويل الكلام إلى سجل منظم بواسطة Gemini.
- حفظ البيانات محلياً على الهاتف.
- تنبيهات محلية للمتابعة.
- إدخال صوتي بالعربية المصرية.
- قسم العاملين: موظف، مرتب، حضور، سلف، وحسابات أساسية.
- شاشة اليوم وبريف رقمي بسيط.

## مهم جداً عن Gemini
النسخة لا تعتمد على `google_generative_ai` القديم. تستخدم Gemini REST API مباشرة مع Structured Output. Google توثق `generateContent` وJSON Structured Output، وتوضح أن `google_generative_ai` Dart SDK القديم deprecated. راجع توثيق Google قبل أي إطلاق تجاري.

## التشغيل للمطور
1. ثبّت Flutter SDK.
2. فك الضغط.
3. افتح المجلد في Android Studio.
4. نفّذ `flutter pub get`.
5. شغّل على هاتف Android.
6. من الإعدادات داخل التطبيق الصق Gemini API Key.

## أسهل طريقة لك كمستخدم غير مبرمج
ارفع ZIP إلى Codemagic، وسيقوم `codemagic.yaml` بإنشاء ملفات Android القياسية ثم يبني APK.

## API Key
لا أضع مفتاحك داخل ZIP. بعد تثبيت التطبيق: الإعدادات → Gemini API Key → الصق المفتاح → حفظ.

## أمثلة للتجربة
- «أحمد عليه 3500 هيدفع الخميس ذكرني الأربعاء»
- «محمد بدأ شغل يوم 4 ومرتبه 4000»
- «محمد خد سلفة 500»
- «سجل حضور محمد النهاردة»

## حدود هذه النسخة
هذه MVP وليست نظام محاسبة أو Payroll قانوني. حساب المرتب مبسط حسب الحضور والسلف، ويحتاج قواعد عملك الفعلية قبل استخدامه مالياً على نطاق واسع.

## التحقق
بيئة التنفيذ الحالية لا تحتوي Flutter SDK، لذلك لم أزعم أن APK بُني هنا. تم تجهيز المشروع وملفات Android وCodemagic، ويجب تنفيذ `flutter pub get` و`flutter build apk --release` في بيئة Flutter فعلية.
